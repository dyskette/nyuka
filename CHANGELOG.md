# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

Nothing is released yet. The backend is complete below the HTTP layer and the
API serves its full route surface; the frontend is scaffolded but not built.

### Added

#### Sources

- Aidoku `.aix` runtime on wasmtime 48: package loading, the 32 host imports
  across `env`, `std`, `net`, `html` and `defaults`, and an install-time
  capability check that refuses a package this build cannot run, naming the
  capability.
- A conformance `.aix` built from a fixture crate, with 53 checks. This is the
  per-commit gate rather than a regression test added afterwards — a host
  cannot be developed against live sites, because a failure there does not
  distinguish a host bug from markup drift.
- `SourceRegistry` over the Aidoku community index, with egress vetting
  applied to index and package downloads.
- Per-source rate limiting that takes the stricter of a source's declared
  limit and the operator's cap.

#### Library and jobs

- CBZ writer with embedded `ComicInfo.xml` v2.0, atomic placement by rename,
  and path sanitization for source-controlled names.
- PostgreSQL job queue using `FOR UPDATE SKIP LOCKED`, with a worker pool that
  drains on `SIGTERM` and a scheduler whose periods come from idempotency keys
  rather than timer accuracy.
- Handlers for downloading, follow checking, metadata refresh, source updates,
  and the three maintenance kinds.

#### API

- OIDC authorization-code flow with PKCE, server-side sessions in PostgreSQL,
  and signed `HttpOnly` cookies. Tokens never reach the browser.
- CSRF as a middleware invariant, rate limiting on `/auth/*` keyed on a
  trust-aware client address, and problem+json (RFC 9457) for every error.
- REST surface for the library, follows, jobs, source repositories, sources,
  the catalog, and downloads with `Range` support.
- SSE at `/api/v1/events`, excluded from response compression.
- OTLP/JSON telemetry ingest with an attribute allow-list.
- The SPA embedded with `rust-embed`, with API paths refused rather than
  falling through to the shell.
- `web/openapi.json` generated by `cargo xtask openapi`, with the typed client
  generated from it. CI fails when either is stale.

#### Observability

- JSON logs with redaction applied at the writer — the one place that sees
  every finished line — and `trace_id` on every line, continued from an
  incoming `traceparent`.
- Hourly `nyuka_metrics` snapshot backing the two objectives in ADR-0019.

### Fixed

Before any release, so these are corrections to unreleased work rather than
to anything shipped. They are listed because each was a control that looked
present and was not:

- Log redaction ran as a `FormatFields` wrapper, which only sees span fields.
  `Format<Json>` serializes event fields directly, so
  `tracing::info!(authorization = …)` passed through untouched.
- The OpenTelemetry text-map propagator was never installed, so an incoming
  `traceparent` was ignored rather than rejected and every request began a new
  trace.
- `trace_id` was declared on the server span and never recorded, so no log
  line carried one.
- `reconcile_library` deleted the file it had just found missing instead of
  clearing the database row that made the UI offer the read.
- The content-hash check for `immutable` caching split on the last hyphen, so
  a Vite hash containing one was misread.

### Documentation

- Architecture decision records 0001–0019 in `docs/adr/`, with an index and a
  template.
- A runbook in `README.md` covering backup and restore, forced logout, the
  identity-provider revocation gap, and the `jq` recipes for evaluating both
  objectives.
- `TODO.md` tracking remaining work, with every item traced to the ADR that
  created it.
- Frontend scaffold under `web/`: Vite 8, React 19, TanStack Router and Query,
  Biome, Lingui. Not yet built out.
- `deny.toml` with a documented, time-boxed exception for RUSTSEC-2023-0071.
- Design tokens in `web/src/app/theme.css`, including four contrast
  corrections found by measuring the proposed palette against WCAG 2.2 AA.
